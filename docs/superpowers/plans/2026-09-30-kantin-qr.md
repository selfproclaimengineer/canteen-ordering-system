# Kantin Order — Plan 4: QR Ordering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Students order from their own Android phone by scanning a table QR, over Tailscale Funnel, only from the school WiFi. The staff surface stays reachable only from the local hotspot.

**Architecture:** One codebase. A Funnel fence middleware recognises internet requests by the `Tailscale-Funnel-Request` header and allows only the QR surface. New `/api/qr/*` routes enforce the QR guards: code, open switch, school IP, 1 active order per device, 50 per minute globally. The ordering UI is extracted into a shared `AlurOrder` component used by the counter screen and a new `/pesan/:kode` page.

**Tech Stack:** as Plans 1–2, plus `qrcode` in `app/`.

**Spec:** `docs/superpowers/specs/2026-09-30-kantin-qr-design.md` (addendum to `2026-09-29-kantin-order-design.md`)

## Global Constraints

- Public request = has header `Tailscale-Funnel-Request`. Sender IP = **last** entry of `X-Forwarded-For`, else socket address.
- Public requests may only hit: `GET /pesan[/x]`, `GET /assets/*`, `GET /manifest.webmanifest`, `GET /api/menu`, `GET /api/qr/ip-saya`, `GET /api/qr/:kode/info`, `GET /api/qr/:kode/orders/:id`, `POST /api/qr/:kode/orders`, `POST /api/qr/:kode/orders/:id/cancel`. Everything else → `404 { error: 'Tidak ditemukan' }`. `/ws` rejects Funnel upgrades.
- QR code: 22 chars from `[A-Za-z0-9]`, compared timing-safe; wrong code or QR feature off (`qr_alamat` or `qr_kode` empty) → `404`.
- Guards apply only to new QR orders: `403 'QR tutup'`, `403 'Bukan WiFi sekolah'` (public requests only), `409 'Masih ada pesanan aktif'` (same device, today, status `baru`), `429 'Terlalu ramai, coba lagi'` (more than **50** QR orders per 60 s). A retry with an existing `client_uuid` skips the guards and returns the original order (200).
- Counter orders (`POST /api/orders`) are never limited.
- Settings keys: `qr_alamat`, `qr_kode`, `qr_buka` (`'0'|'1'`, default closed), `qr_ip` (JSON array).
- `orders.sumber` is `'kasir' | 'qr'`, default `'kasir'`, added by an automatic migration in `openDb`.
- iPhone is not supported (cannot join the school WiFi). No mobile-data path now.
- QR page: no hidden corner, no PIN, no idle reset; status poll every 5 s; vibrate on "siap".

## Review Focus

1. An attacker prepends a fake school IP: `X-Forwarded-For: 114.10.1.1, 8.8.8.8` → rejected, because only the last entry counts (Task 3).
2. A student's phone retries the same order (same `client_uuid`) while it is still `baru` → gets the original order back, not `409` (Task 3).
3. A bot opens `wss://…/ws` through Funnel → the upgrade is refused, so kitchen events never leak (Task 2).
4. The kantin updates a laptop that already has a database without the `sumber` column → the server starts and old orders count as `kasir` (Task 1).
5. The phone-only variant with QR switched off (`qr_alamat` empty) → every `/api/qr/*` route answers `404` and the kitchen shows no QR button (Tasks 3, 6).

```ts
import { randomInt, timingSafeEqual } from 'node:crypto';
import type { Request, RequestHandler } from 'express';
import type { Clock } from './clock';
import type { Db } from './db';
import { getSetting } from './settings';

const ALFABET = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789';

export function buatKodeQr(): string {
  return Array.from({ length: 22 }, () => ALFABET[randomInt(ALFABET.length)]).join('');
}

export function samaAman(a: string, b: string): boolean {
  const x = Buffer.from(a);
  const y = Buffer.from(b);
  return x.length === y.length && timingSafeEqual(x, y);
}

/** Tailscale Funnel adds this header to every request that comes from the internet. */
export function lewatFunnel(req: Request): boolean {
  return req.header('tailscale-funnel-request') !== undefined;
}

/** The last X-Forwarded-For entry is the one the proxy added; earlier ones come from the client. */
export function ipPengirim(req: Request): string {
  const akhir = req.header('x-forwarded-for')?.split(',').pop()?.trim();
  return akhir || req.socket.remoteAddress || '';
}

export interface AturQr {
  alamat: string;
  kode: string;
  buka: boolean;
  ip: string[];
}

export function bacaQr(db: Db): AturQr {
  return {
    alamat: getSetting(db, 'qr_alamat') ?? '',
    kode: getSetting(db, 'qr_kode') ?? '',
    buka: getSetting(db, 'qr_buka') === '1',
    ip: JSON.parse(getSetting(db, 'qr_ip') ?? '[]') as string[],
  };
}

export const qrAktif = (q: AturQr) => q.alamat !== '' && q.kode !== '';

const PUBLIK: [string, RegExp][] = [
  ['GET', /^\/pesan(\/[^/]*)?$/],
  ['GET', /^\/assets\//],
  ['GET', /^\/manifest\.webmanifest$/],
  ['GET', /^\/api\/menu$/],
  ['GET', /^\/api\/qr\/ip-saya$/],
  ['GET', /^\/api\/qr\/[A-Za-z0-9]+\/info$/],
  ['GET', /^\/api\/qr\/[A-Za-z0-9]+\/orders\/\d+$/],
  ['POST', /^\/api\/qr\/[A-Za-z0-9]+\/orders$/],
  ['POST', /^\/api\/qr\/[A-Za-z0-9]+\/orders\/\d+\/cancel$/],
];

/** Internet requests may only use the QR ordering surface; the staff surface stays local. */
export const pagarFunnel: RequestHandler = (req, res, next) => {
  if (!lewatFunnel(req)) return next();
  const metode = req.method === 'HEAD' ? 'GET' : req.method;
  if (PUBLIK.some(([m, pola]) => m === metode && pola.test(req.path))) return next();
  res.status(404).json({ error: 'Tidak ditemukan' });
};

/** Sliding-window limit shared by all QR orders. Per-IP limits would block the whole school NAT. */
export class BatasLaju {
  private waktu: number[] = [];

  constructor(private clock: Clock, private maks = 50, private jendelaMs = 60_000) {}

  boleh(): boolean {
    const now = this.clock.now();
    this.waktu = this.waktu.filter((t) => now - t < this.jendelaMs);
    if (this.waktu.length >= this.maks) return false;
    this.waktu.push(now);
    return true;
  }
}
```

```ts
import { type Request, Router } from 'express';
import { isIP } from 'node:net';
import { z } from 'zod';
import { totalOrder } from '../../shared/pricing';
import { tanggalDari } from '../../shared/rules';
import { batalPelangganSchema, orderBaruSchema, qrAturSchema, qrBukaSchema, qrIpSchema } from '../../shared/schemas';
import type { Ctx } from '../context';
import { get } from '../db';
import { HttpError, idParam, parse, requireRole } from '../http';
import { adaOrderQrAktif, ambilOrder, batalPelanggan, buatOrder } from '../order-repo';
import { type AturQr, bacaQr, buatKodeQr, ipPengirim, lewatFunnel, qrAktif, samaAman } from '../qr';
import { getPengaturan, setSetting } from '../settings';

export function qrRoutes(ctx: Ctx): Router {
  const r = Router();

  const cekKode = (req: Request): AturQr => {
    const q = bacaQr(ctx.db);
    if (!qrAktif(q) || !samaAman(String(req.params.kode), q.kode)) throw new HttpError(404, 'Tidak ditemukan');
    return q;
  };
  // Local hotspot requests are trusted; only internet requests must come from the school IP.
  const jaringanOk = (req: Request, q: AturQr) => !lewatFunnel(req) || q.ip.includes(ipPengirim(req));

  r.get('/qr/ip-saya', (req, res) => {
    res.json({ ip: ipPengirim(req) });
  });

  r.get('/qr/:kode/info', (req, res) => {
    const q = cekKode(req);
    res.json({ buka: q.buka, jaringan_ok: jaringanOk(req, q) });
  });

  r.post('/qr/:kode/orders', (req, res) => {
    const q = cekKode(req);
    const input = parse(orderBaruSchema, req.body);
    const now = ctx.clock.now();
    // A retry of an existing order skips the guards and gets the original back.
    if (!get(ctx.db, 'SELECT 1 AS x FROM orders WHERE client_uuid = ?', input.client_uuid)) {
      if (!q.buka) throw new HttpError(403, 'QR tutup');
      if (!jaringanOk(req, q)) throw new HttpError(403, 'Bukan WiFi sekolah');
      if (adaOrderQrAktif(ctx.db, input.device, tanggalDari(now))) throw new HttpError(409, 'Masih ada pesanan aktif');
      if (!ctx.batasQr.boleh()) throw new HttpError(429, 'Terlalu ramai, coba lagi');
    }
    const { order, baru } = buatOrder(ctx.db, input, now, getPengaturan(ctx.db).qty_max, 'qr');
    if (baru) ctx.emit({ type: 'orders-changed' });
    res.status(baru ? 201 : 200).json({ id: order.id, nomor: order.nomor, total: totalOrder(order.items), dibuat_at: order.dibuat_at });
  });

  r.get('/qr/:kode/orders/:id', (req, res) => {
    cekKode(req);
    const uuid = parse(z.uuid(), req.query.uuid);
    const o = ambilOrder(ctx.db, idParam(req.params.id));
    if (!o || o.sumber !== 'qr' || o.client_uuid !== uuid) throw new HttpError(404, 'Order tidak ditemukan');
    res.json({ id: o.id, nomor: o.nomor, status: o.status, total: totalOrder(o.items) });
  });

  r.post('/qr/:kode/orders/:id/cancel', (req, res) => {
    cekKode(req);
    const { client_uuid } = parse(batalPelangganSchema, req.body);
    const o = batalPelanggan(ctx.db, idParam(req.params.id), client_uuid, ctx.clock.now());
    ctx.emit({ type: 'orders-changed' });
    res.json({ status: o.status });
  });

  const dapur = requireRole(ctx, 'dapur');

  r.get('/dapur/qr', dapur, (_req, res) => {
    const q = bacaQr(ctx.db);
    res.json({ aktif: qrAktif(q), buka: q.buka });
  });

  r.put('/dapur/qr', dapur, (req, res) => {
    const { buka } = parse(qrBukaSchema, req.body);
    setSetting(ctx.db, 'qr_buka', buka ? '1' : '0');
    ctx.emit({ type: 'menu-changed' });
    res.json({ buka });
  });

  return r;
}

export function adminQrRoutes(ctx: Ctx): Router {
  const r = Router();

  r.get('/qr', (_req, res) => {
    res.json(bacaQr(ctx.db));
  });

  r.put('/qr', (req, res) => {
    const { alamat, buka } = parse(qrAturSchema, req.body);
    setSetting(ctx.db, 'qr_alamat', alamat.replace(/\/+$/, ''));
    if (alamat && !bacaQr(ctx.db).kode) setSetting(ctx.db, 'qr_kode', buatKodeQr());
    setSetting(ctx.db, 'qr_buka', buka ? '1' : '0');
    ctx.emit({ type: 'menu-changed' });
    res.json(bacaQr(ctx.db));
  });

  r.post('/qr/ganti-kode', (_req, res) => {
    setSetting(ctx.db, 'qr_kode', buatKodeQr());
    res.json(bacaQr(ctx.db));
  });

  r.put('/qr/ip', (req, res) => {
    const { ip } = parse(qrIpSchema, req.body);
    if (!ip.every((x) => isIP(x) !== 0)) throw new HttpError(400, 'IP tidak valid');
    setSetting(ctx.db, 'qr_ip', JSON.stringify([...new Set(ip)]));
    res.json(bacaQr(ctx.db));
  });

  // The server sits on the school WiFi, so calling its own public address shows the school's public IP.
  r.post('/qr/ambil-ip', async (_req, res) => {
    const q = bacaQr(ctx.db);
    if (!q.alamat) throw new HttpError(400, 'Isi alamat publik dulu');
    let ip = '';
    try {
      const jawab = await ctx.fetchFn(`${q.alamat}/api/qr/ip-saya`, { signal: AbortSignal.timeout(8000) });
      if (jawab.ok) ip = String(((await jawab.json()) as { ip?: unknown }).ip ?? '');
    } catch {
      throw new HttpError(502, 'Alamat publik tidak bisa dihubungi. Cek Funnel dan internet.');
    }
    if (isIP(ip) === 0) throw new HttpError(502, 'IP tidak terbaca. Cek Funnel dan internet.');
    setSetting(ctx.db, 'qr_ip', JSON.stringify([...new Set([...q.ip, ip])]));
    res.json({ ...bacaQr(ctx.db), ip_baru: ip });
  });

  return r;
}
```

```tsx
    window.localStorage.setItem('qr-device', d);
  }

    return JSON.parse(window.localStorage.getItem(KUNCI_LACAK) ?? 'null') as Lacak | null;
  } catch {
    return null;
  }

    else window.localStorage.removeItem(KUNCI_LACAK);
    setLacak(l);
    setStatus(null);
    sudahGetar.current = false;
  }, []);

  const muat = useCallback(async () => {
    try {
      const [menu, info] = await Promise.all([
        api<DataMenu>('/menu'),
        api<{ buka: boolean; jaringan_ok: boolean }>(`/qr/${kode}/info`),

      setInfoQr(info);
      setGalat('');
    } catch (e) {
      if (e instanceof ApiError && e.status === 404) setGalat('QR tidak berlaku');
    }
  }, [kode]);

  useEffect(() => {
    void muat();
    const t = window.setInterval(() => void muat(), 30_000);
    return () => clearInterval(t);

        if (!hidup) return;
        setStatus(s.status);
        if (s.status === 'siap' && !sudahGetar.current) {
          sudahGetar.current = true;
          navigator.vibrate?.([300, 150, 300, 150, 300]);
        }

      }

      setStatus('batal');
    } catch (e) {
      alur.setInfo({ teks: e instanceof Error ? e.message : 'Gagal', nada: 'merah' });
    }
  };

  return (
    <div className="layar">
```

Append to `README.md`:
```markdown
## QR ordering (optional, laptop recommended)

Students scan a QR on the table and order from their own Android phone over the school WiFi. Only the server needs Tailscale; student phones use a normal browser.

1. The server (laptop, or a host phone that supports WiFi + hotspot at the same time) joins the school WiFi and shares a hotspot with the kantin phones.
2. Run `npm start`, then `tailscale funnel --bg 3000`. Tailscale prints the public address, e.g. `https://kantin.xxx.ts.net`.
3. On a kantin phone: Dapur → Edit → **QR**. Paste the address, save, press **Ambil IP sekolah**, then **Cetak**.
4. Open or close QR ordering with the **QR: Buka/Tutup** button in Dapur.

Safety:

- Requests from the internet can only reach the QR ordering page. Dapur, Edit, Laporan and PIN login work only on the kantin hotspot.
- QR orders are accepted only from the school's public IP, at most one active order per phone, and at most 50 QR orders per minute.
- If a QR photo leaks, press **Ganti kode** and print the new QR.
- To switch the feature off, clear the address in Edit → QR, or run `tailscale funnel --https=443 off`.

iPhones cannot join the school WiFi, so they are not supported for QR ordering; they can order at the counter.

On a host phone, Funnel needs the community `tailscale-termux-cli` in Termux. It is experimental: test it before relying on it.
```
